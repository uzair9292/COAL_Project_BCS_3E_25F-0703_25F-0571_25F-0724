COAL standalone starter files (not final submission)
Each ASM is independent, with a duplicate test harness. Do not combine whole files.
Build with NASM in DOSBox: nasm engine.asm -o engine.com (or graphics/gameplay).
Controls: Up/Down, Enter, arrows, P, D=simulate death, W=simulate win, Esc.
Title green upper bar=start; red lower bar=exit. Screens are placeholders.
All three use the same engine test code; teammates replace only assigned routines.
Lab style: [org 0x0100], ordinary named labels, hexadecimal 0x notation, data labels with colons. Constants use lowercase; public procedure names stay unchanged. Only [org 0x0100] is used at the top. No extra compilation flags or include files are needed. Indentation and procedure comments are retained because the project requires them.

COMMON CONTRACT
DS=CS except within saved/restored segment operations. All draw to framebuffer_seg.
Word stack arguments pushed right to left via MOV/PUSH; callee RET n.
Preserve registers except documented outputs. DF clear. No PUSH immediate or 32-bit registers.
Positions mario_x and mario_y: two words, low word first, signed fixed point scaled by 256 (24.8 storage to cover 960 pixels). y is sprite TOP. Velocity signed 8.8 words. camera_x integer pixels.
HP 1 or 2; form 0/1, facing 0 right/1 left, pose 0 stand/1 run/2 jump.
keys_held and keys_pressed indexed by scan code. Core owns countdown, states, life decrement and resets. Gameplay sets death_request=1 normal/2 pit, win_request=1 and flag_points; core awards flag points.
Aleena: ResetMap, DrawMap, DrawHero, UpdateCamera, plus PutPixel(x,y,colour), FillRect(x,y,w,h,colour), DrawTile(x,y,tile), GetTile(px,py) returns AX tile, DrawSprite(x,y,address,flags). Sprite layout: byte width, byte height, then row-major palette bytes; flags bit 0 mirror. Map tile codes follow Appendix A.2. Expose original_map and working_map (720 bytes each, row-major). GetTile uses whole world pixels, returns 0 for outside map (gameplay handles boundaries).
Nawal: ResetEntities, UpdatePlayer, UpdateEnemies, UpdateItems, CheckCollisions, DrawEntities, DrawHUD, AddScore(points). Use temporary test map until Aleena's map is ready; implement a temporary GetTile with same stack interface. Keep any private data uniquely named. AddScore clamps 999999. Core calls AddScore for flag and time bonuses. DrawHUD and entities draw into framebuffer, never present themselves.
